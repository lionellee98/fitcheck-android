# 健身打卡 App（PWA）— 交付概览

基于 `exercise-dataset-zh` 技能（1,324 个动作 + 演示 GIF）打造的**极简本地健身打卡应用**，移动端优先、卡片化、数据全部本地留存。

## 技术形态
- 移动端 PWA（HTML + CSS + 原生 JS），可「添加到主屏幕」像原生 App 使用。
- 纯本地：数据存 `localStorage`，无网络、无后端、无 API key。
- 数据源：`data/exercises.min.json`（由技能数据精简生成，1.27 MB）+ `assets/videos/`（1,324 个演示 GIF）。

## 四大页面
1. **每日计划**：AI 按身体情况建议时长（自定义）/ 选环境（健身房·居家·室外）→ 生成顺序动作表；逐动作可看详情与跟练，**跟练带计时 + AI 教练提示**；完成后写入当日打卡与卡路里消耗。
2. **本月进度**：本月打卡天数/消耗/动作数、日历视图（点日看详情）、各部位打卡次数统计、月度总结。
3. **动作指导**：按锻炼区域分模块展示，顶部搜索支持**肌肉别名联想 + 模糊搜索**（如「肩中束」「卧推」），点开看 GIF + 要领 + 分步文字。
4. **身体情况**：填体重/身高 → BMI + 增肌/减脂/维持建议；上传照片 → **本地 AI 姿态分析**（TensorFlow.js + MoveNet，检测关键点/对称性，启发式给出需加强部位，照片不出设备）并可一键应用到每日计划；也可手动勾选加强部位。

## 其他
- 每日打开弹「打鸡血」鼓励弹窗（每天一次）。
- 明暗主题切换（跟随系统，可手动），流畅过渡。
- 「AI」为**本地启发式**（数据集 + 用户指标驱动），非云端大模型，以保证完全离线。

## 如何在安卓上使用
- 本地预览：已起静态服务 `http://127.0.0.1:3000/`，可直接在浏览器/预览面板打开。
- 安卓真机：将 `fitness-app/` 目录部署到任意静态托管（或同一 Wi-Fi 下用电脑 IP 访问），在 Chrome 打开 → 「添加到主屏幕」即成为可离线使用的 App。
- 若要真正 `.apk`：可用 Capacitor/Tauri 包装此 PWA。

## 已知取舍
- 照片分析为**本地姿态/对称性启发式评估**（TensorFlow.js + MoveNet），用于给出"建议加强部位"，非医学体脂/体态诊断。首次使用需联网下载模型权重（几 MB），之后可离线；Android 端已加回 INTERNET 权限。
- 卡路里/计划为启发式估算，供激励参考。
